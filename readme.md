# Sistema de Gestão de Equipamentos de TI

Sistema web desenvolvido como projeto acadêmico para auxiliar no controle de equipamentos de TI de uma empresa, permitindo gerenciar os equipamentos e acompanhar quem está utilizando cada um.

## Tecnologias utilizadas

- **PHP puro** — lógica e processamento do sistema.
- **MySQL** — armazenamento e gerenciamento dos dados.
- **HTML5** — estrutura das páginas.
- **Bootstrap** — estilização e responsividade.
- **CSS3** — personalização visual.
- **JavaScript** — interatividade.

## Funcionalidades previstas

- Autenticação de usuários.
- Controle de acesso por perfil (administrador e usuário comum).
- Cadastro, consulta, edição e exclusão de equipamentos.
- Cadastro e gerenciamento de usuários.
- Registro de entrega e devolução de equipamentos.
- Histórico de movimentações.

## Segurança e integridade dos dados

- Prepared statements com PDO para consultas ao banco de dados.
- Hash de senhas com funções nativas do PHP.
- Validação dos dados recebidos.
- Controle de sessões e permissões de acesso.
- Restrições no banco de dados para manter a consistência das informações.
